SISTEMA DE TREINAMENTO E CAPACITAÇÃO

Implementado:
- Tela inicial de login.
- Validação de campos vazios no login.
- Limpeza dos campos do login.
- Acesso do login para o dashboard.
- Dashboard com cabeçalho, menu lateral e visão geral.
- Indicadores de treinamentos e participantes.
- Atalhos visuais para funções principais.
- Tela inicial de treinamentos.
- Tela de cadastro de treinamento.
- Campos de nome, tipo, descrição, carga horária, datas, instrutor, instituição e local.
- Campo de instituição habilitado somente para treinamento externo.
- Validação básica de campos obrigatórios.
- Botões de cadastrar, limpar e voltar.
- CSS básico nas telas.

Não implementado:
- Autenticação real de usuários e perfis.
- Armazenamento dos treinamentos.
- Consulta e filtros de treinamentos.
- Edição e exclusão de treinamentos.
- Cadastro de bombeiros, instrutores e instituições.
- Participações e certificados.
- Persistência dos dados.
